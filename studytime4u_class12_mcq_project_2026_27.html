1. Introduction

Multiple-choice questions (MCQs) are commonly used for practice and revision because they can cover many topics in a short time. Checking answers manually can take time, especially when the same quiz is attempted repeatedly. A small quiz program can automate answer checking and score calculation.

1.1 Problem Statement

To develop a simple and reliable application that presents a set of MCQs, accepts answers, calculates a score, shows the result, and saves the attempt to a file for later reference.

1.2 Aim

To apply Class XI and XII Python concepts to create a useful quiz application using functions, selection, iteration, data structures, exception handling, and file handling.

1.3 Objectives

  • Display a question with four answer options.
  • Accept only valid choices A, B, C, or D.
  • Compare the selected option with the answer key.
  • Calculate correct answers, incorrect answers, and percentage.
  • Provide simple feedback after each question.
  • Save the student's name, score, total questions, percentage, and date/time to a CSV file.
  • Handle invalid input and file errors without abruptly terminating the program.

1.4 Scope

This is a local, single-user learning prototype. It contains sample Computer Science questions and stores results on the computer where it runs. It does not require internet access, user accounts, or paid software.

1.5 Limitations

  • The sample question bank is stored inside the Python program; adding questions requires editing the code.
  • The CSV result file is local and is not a secure multi-user database.
  • The program is not designed for high-stakes examinations, proctoring, or simultaneous online users.
  • Saved CSV records should be handled responsibly and should not contain unnecessary personal information.

4. System Design

4.1 Input, Process and Output

InputProcessOutput
Student name; option A/B/C/D for each questionValidate input, compare answer, count score, compute percentage, write CSV rowPer-question feedback, final score, percentage, saved result message

4.2 Algorithm

  1. Start the program.
  2. Display the project title and ask for the student's name.
  3. Set the correct-answer counter to zero and create an empty attempt stack.
  4. For each question in the question bank, display the question and options.
  5. Accept a response until A, B, C, or D is entered.
  6. Push the question number onto the attempt stack.
  7. Compare the response with the answer key. If it matches, increase the score.
  8. After all questions, calculate percentage = correct answers ÷ total questions × 100.
  9. Display the final score and percentage.
  10. Append the result and timestamp to the CSV file; report any file error.
  11. End the program.

4.4 Data Structure

Each question is represented as a dictionary containing a question string, a list of four options, and the correct option letter. A list holds all question dictionaries. A second list acts as a stack by appending question numbers as they are attempted.

5. Python Source Code

File name: mcq_exam.py

Type or copy the following code into a Python editor and save it as mcq_exam.py. Run it using Python 3. The code creates quiz_results.csv in the current working folder after the first completed quiz.

"""
Project: MCQ-Based Examination Software
Class XII Computer Science (083)
Python 3 - uses built-in modules only.
"""

import csv
import os
from datetime import datetime

QUESTIONS = [
    {
        "question": "Which Python keyword is used to define a function?",
        "options": ["A. func", "B. define", "C. def", "D. function"],
        "answer": "C"
    },
    {
        "question": "Which file mode appends data to a text file?",
        "options": ["A. r", "B. a", "C. x", "D. t"],
        "answer": "B"
    },
    {
        "question": "Which Python data structure follows LIFO?",
        "options": ["A. Queue", "B. Stack", "C. String", "D. Tuple"],
        "answer": "B"
    },
    {
        "question": "Which CSV module object is commonly used to read rows?",
        "options": ["A. csv.reader", "B. csv.open", "C. csv.scan", "D. csv.input"],
        "answer": "A"
    },
    {
        "question": "Which SQL command retrieves data from a table?",
        "options": ["A. UPDATE", "B. DELETE", "C. SELECT", "D. ALTER"],
        "answer": "C"
    },
    {
        "question": "Which protocol is used for secure web communication?",
        "options": ["A. HTTP", "B. FTP", "C. HTTPS", "D. SMTP"],
        "answer": "C"
    },
    {
        "question": "Which clause filters rows before grouping in SQL?",
        "options": ["A. WHERE", "B. ORDER BY", "C. AS", "D. DISTINCT"],
        "answer": "A"
    },
    {
        "question": "Which block is used to handle a possible Python exception?",
        "options": ["A. check", "B. try-except", "C. repeat", "D. switch"],
        "answer": "B"
    },
    {
        "question": "What does a primary key identify in a relational table?",
        "options": ["A. Duplicate rows", "B. Each row uniquely",
                    "C. Only text", "D. A file path"],
        "answer": "B"
    },
    {
        "question": "Which function converts a string to lowercase?",
        "options": ["A. lower()", "B. small()", "C. lowercase()", "D. case()"],
        "answer": "A"
    }
]

RESULT_FILE = "quiz_results.csv"


def get_valid_choice():
    """Return a valid answer choice: A, B, C or D."""
    while True:
        choice = input("Your answer (A/B/C/D): ").strip().upper()
        if choice in ("A", "B", "C", "D"):
            return choice
        print("Invalid choice. Please enter A, B, C or D.")


def calculate_percentage(score, total):
    """Return score percentage, protecting against division by zero."""
    if total == 0:
        return 0.0
    return (score / total) * 100


def save_result(name, score, total, percentage):
    """Append one result row to a CSV file."""
    file_exists = os.path.exists(RESULT_FILE)
    try:
        with open(RESULT_FILE, "a", newline="", encoding="utf-8") as file:
            fields = ["date_time", "student_name", "score",
                      "total_questions", "percentage"]
            writer = csv.DictWriter(file, fieldnames=fields)
            if not file_exists or os.path.getsize(RESULT_FILE) == 0:
                writer.writeheader()
            writer.writerow({
                "date_time": datetime.now().strftime("%Y-%m-%d %H:%M:%S"),
                "student_name": name,
                "score": score,
                "total_questions": total,
                "percentage": f"{percentage:.2f}"
            })
        print("Result saved in", RESULT_FILE)
    except OSError as error:
        print("Could not save the result:", error)


def run_quiz():
    """Conduct the quiz and display the final result."""
    print("=" * 48)
    print("       STUDYTIME4U - MCQ EXAM SOFTWARE")
    print("=" * 48)

    name = input("Enter your name: ").strip()
    if not name:
        name = "Guest"

    score = 0
    attempt_stack = []  # List used as a stack: latest question is last.

    for number, item in enumerate(QUESTIONS, start=1):
        print("\nQuestion", number, "of", len(QUESTIONS))
        print(item["question"])
        for option in item["options"]:
            print(" ", option)

        choice = get_valid_choice()
        attempt_stack.append(number)  # PUSH operation

        if choice == item["answer"]:
            print("Correct answer!")
            score += 1
        else:
            print("Incorrect. Correct option:", item["answer"])

    total = len(QUESTIONS)
    percentage = calculate_percentage(score, total)

    print("\n" + "=" * 48)
    print("RESULT FOR:", name)
    print("Score:", score, "/", total)
    print("Percentage: {:.2f}%".format(percentage))
    print("Questions attempted:", len(attempt_stack))
    print("Latest attempted question (stack top):", attempt_stack[-1])
    print("=" * 48)

    save_result(name, score, total, percentage)


if __name__ == "__main__":
    try:
        run_quiz()
    except (KeyboardInterrupt, EOFError):
        print("\nQuiz ended before completion. No final result was saved.")

6.1 Why use a CSV file?

CSV stands for Comma-Separated Values. It stores tabular data in a plain-text format that can be opened by a text editor or spreadsheet program. The Python csv module handles quoting and separators more reliably than manually joining strings.

6.2 Why use exception handling?

The result file may not be writable if the folder is read-only or storage is unavailable. The try/except block displays a useful error message instead of hiding the reason for the failure. The outer exception handler handles a user who interrupts the quiz.

6.3 Why use a stack?

A stack follows Last In, First Out (LIFO). The program appends each attempted question number to a list. The last number in the list represents the most recently attempted question. This demonstrates stack-style insertion; the core program does not use a POP operation because it does not need to remove questions.

6.4 Accuracy note

The current program shows the correct option after an incorrect response. It saves only the final total score, not each individual response. The CSV file is a record of attempts, not a secure database.
